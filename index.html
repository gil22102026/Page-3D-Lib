P3D

Declarative 3D for the web via simple HTML tags. No JS boilerplate. No build tools.

v0.1.0 Three.js 0.160 ~43KB Source Available

Introduction

P3D Viewer is a lightweight library that brings 3D graphics directly into HTML. It uses custom HTML elements (like <p3d-scene> and <p3d-sphere>) to describe 3D scenes declaratively, without writing any JavaScript rendering code.

Key features True background transparency, smart relative/absolute animations, PBR materials, mobile touch controls, and automatic off-screen pausing for peak performance.

Installation

Just include the library script in your HTML. No npm, no bundler required.

<script src="https://gil22102026.github.io/Page-3D-Lib/index.js"></script>

Quick Start

Create your first 3D scene in 3 lines of HTML:

<p3d-scene controls="orbit" theme="transparent" style="height: 400px;">
  <p3d-sphere radius="1" color="#58a6ff" anim-type="rotate"></p3d-sphere>
</p3d-scene>

That's it. A rotating blue sphere with transparent background and orbit controls.

p3d-scene

The container for all 3D objects. Handles camera, rendering, and performance.

AttributeTypeDescription
controlsstring"orbit" enables mouse/touch camera control.
themecolorBackground color. Use "transparent" to show page background.
fogstringLinear: "#hex, near, far". Exponential: "#hex, density".
no-default-lightbooleanDisables default studio lighting.
scroll-throughbooleanAllows vertical page scroll over the scene (mobile).
fpsnumberLimits FPS (e.g., 30) to save battery.
fovnumberCamera field of view (default: 50).

Primitives

Built-in geometric shapes. No file loading required.

TagKey Attributes
<p3d-sphere>radius, segments
<p3d-box>size (e.g., "1,1,1")
<p3d-cylinder>radius, height
<p3d-cone>radius, height
<p3d-pyramid>radius, height

All primitives share common attributes: pos, rot, scale, color, metalness, roughness, opacity, wireframe, emissive.

External Models

Load complex models from Blender, Sketchfab, etc. using <p3d-extern-model>:

<p3d-extern-model src="./model.glb" scale="1,1,1"></p3d-extern-model>

Supports .glb and .gltf formats.

Lights

Add custom lighting with <p3d-light>:

<p3d-scene no-default-light>
  <p3d-sphere radius="1" color="#ffffff"></p3d-sphere>
  <p3d-light type="point" color="#ff0000" intensity="5" pos="-3, 2, 2"></p3d-light>
  <p3d-light type="point" color="#0000ff" intensity="5" pos="3, 2, 2"></p3d-light>
</p3d-scene>

Available types: ambient, directional, point, spot.

Materials & Patterns

Full PBR (Physically Based Rendering) support:

AttributeRangeDescription

roughness0.0 – 1.0Surface roughness. 0.0 = glossy, 1.0 = matte.

Animations

Built-in animations: rotate, float, pulse.

Animation Modes

The anim-mode attribute controls how animations interact with base coordinates:

ModeBehavior
absolute (default)Animation overrides base coordinates. Object teleports to animation origin.
relativeAnimation is applied on top of base coordinates. Object stays in place and animates around it.
 
<!-- Floats around its own position (2, 1, 0) -->
<p3d-box pos="2, 1, 0" anim-type="float" anim-mode="relative"></p3d-box>

<!-- Floats at origin (0, 0, 0), ignoring pos -->
<p3d-box pos="2, 1, 0" anim-type="float" anim-mode="absolute"></p3d-box>

Animation Attributes

AttributeExampleDescription
anim-type"rotate"Name of the animation.
anim-duration"3s"Duration of one cycle.
anim-iteration"infinite" or numberLoop count.
anim-easing"ease-in-out"Motion curve.
anim-mode"absolute" or "relative"Coordinate mode.

Interaction

Add clickable attribute to listen for native DOM events:

<p3d-box id="btn" clickable color="#58a6ff"></p3d-box>

<script>
  const btn = document.getElementById('btn');
  
  btn.addEventListener('p3d-click', (e) => {
    console.log('Clicked at:', e.detail.point);
    btn.setAttribute('color', '#f85149');
  });
  
  btn.addEventListener('p3d-hover', (e) => {
    if (e.detail.hovered) {
      btn.setAttribute('emissive', '#400040');
    } else {
      btn.setAttribute('emissive', '#000000');
    }
  });
</script>

JavaScript API

Register Custom Animation

P3D.registerAnimation('wobble', {
  '0%':   { rotation: [0, 0, 0] },
  '25%':  { rotation: [0.1, 0, 0.1] },
  '50%':  { rotation: [0, 0, 0] },
  '75%':  { rotation: [-0.1, 0, -0.1] },
  '100%': { rotation: [0, 0, 0] }
}, { easing: 'ease-in-out' });

Dynamic Attribute Changes

const sphere = document.querySelector('p3d-sphere');
sphere.setAttribute('pos', '2, 1, 0');
sphere.setAttribute('color', '#3fb950');

Performance

Automatic optimization Scenes automatically pause WebGL rendering when off-screen (via Intersection Observer) while maintaining animation logic. This saves battery and CPU without breaking animations.
  • Off-screen pausing: Rendering stops when not visible, but animation time continues.
  • FPS limiting: Use fps="30" to reduce power consumption.
  • Frustum culling: Objects outside camera view are automatically hidden.
  • Context management: WebGL contexts are dynamically created/destroyed to avoid browser limits.
