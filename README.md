# Page-3D-Lib

Not all functions and features are currently operating as intended. But most functions and features work fine.

P3D Viewer: Declarative 3D for the web via simple HTML tags. No JS boilerplate. Features true background transparency, smart relative/absolute animations, PBR materials, click controls, auto-pause for peak performance, and other features. Perfect for interactive, floating 3D elements.

Last version: [last version .txt file](./LastVersion.txt). You can use for dynamic updates check. Old versions saved as old-<version>.js(for example: old-0.1.0.js). Last version saved as index.js.
